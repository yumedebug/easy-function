# 太郎の日常便利ツール v2.8

日常を少しでも快適にするためのシンプルなコンソールツールです。

## 機能一覧

### ✅ 主な機能
- **ToDoリスト管理**
  - タスクの追加・削除
  - 完了/未完了の切り替え
  - **期限日付設定**（YYYY-MM-DD）
  - 期限切れ・今日期限・近日中の自動色分け

- **期限リマインダー**
  - 起動時・画面更新時に自動で警告表示
  - 期限切れ・今日まで・近日中を強調通知

- **強力パスワード生成**
  - 20文字の安全なパスワードを即生成
  - 生成履歴を `fupassword.txt` に自動保存（日時付き）

- **マルチタイマー**
  - 1分 / 3分 / 5分 / 10分 / 30分
  - カスタム秒数入力可能
  - 残り時間少なくなると色が変わる

- **カラフル表示**
  - 見やすい色分け（タイトル・警告・期限など）

## ファイル構成

- `functionver2.exe` … 実行ファイル
- `todotsk.txt` … ToDoリストの保存ファイル
- `fupassword.txt` … 生成したパスワードの履歴

## 使い方

1. `functionver2.exe` をダブルクリックで起動
2. 数字を入力して各機能を使用
3. ToDo追加時に期限を入力したい場合は `2026-05-20` の形式で入力（不要ならEnter）

### 操作メニュー
| 番号 | 機能 |
|------|------|
| 1 | 強力パスワード生成 |
| 2 | ToDo追加（期限付き可） |
| 3 | ToDo完了/未完了切替 |
| 4 | ToDo削除 |
| 5 | タイマー |
| 6 | 終了 |
